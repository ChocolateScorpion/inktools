About InkTools

InkTools is a collection of simple, fast, and privacy-focused online tools designed to solve everyday problems.

The project started from a real issue: iPhone photos in HEIC format often don’t open properly on Windows or other devices. Existing solutions required uploading files to external servers, which raised privacy concerns.

InkTools was built to solve that problem differently. All tools run directly in your browser, meaning your files never leave your device.

Our goal is to create useful tools that are fast, simple, and respect user privacy.
